# Weather App 🌦️

A weather application built with React and Vite that provides a simple and user-friendly interface for checking weather information.

## Features
- View weather information through a web interface.
- Interactive and responsive user interface.
- Integration with a weather API.

## Tech Stack
- React
- JavaScript
- HTML
- CSS
- Vite

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/HasiniL2780/weather-app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd weather-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
